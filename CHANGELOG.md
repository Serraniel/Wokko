# Changelog

## 0.1.0

The first version of the rewrite, built for stability on SQLite in a single small container.

### Features

* **recipes:** steps with their own ingredients, photos, tags, scaling, search, cook log, trash and version history
* **recipes:** import from links and pasted text, cooking mode with timers, printing and recipe books
* **plan:** meal plans, a shared shopping list sorted by aisle, and nutrition estimates
* **sharing:** households, friends, public recipes and share links, with no way to search for people
* **backup:** verified automatic backups, safety checks on start and a simple restore
* **kitshn:** use the kitshn mobile app, including creating and editing
* **mcp:** connect Claude and other assistants through MCP, off by default
* **auth:** invites, admin reset links and passkeys
* **i18n:** English and German, and adding a language takes one file
